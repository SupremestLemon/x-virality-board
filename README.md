# Tom's X desk (x-virality-board)

Personal GitHub Pages board for the X virality desk (@Chalcedon).
Scaffolded from the `board/` starter in monkeyteamvip/x-virality-score.

- `index.html`: the board page. It loads `./data.json`.
- `data.json`: the day's digest data. Replace this file after each daily digest.
- `config/watchlist.json`: timezone, view thresholds, and the watched handles.

Read-only tooling. No visitor tracking. Not affiliated with X Corp.
